# Digital Twin Maturity Levels Framework

This repository provides a clean, modular Python reference implementation that demonstrates the three core stages of the **Digital Twin (DT) Maturity Spectrum**:

1. **Level 1: Partial Digital Twin** (Component Observer)
2. **Level 2: Digital Twin Clone** (High-Fidelity State Mirror & Actuator)
3. **Level 3: Augmented Digital Twin** (Predictive Optimizer & Scenario Simulator)

## Architectural Progression

## Code Breakdown by Maturity Level

### 1. Data Contract: `AssetTelemetry`

Standardizes the ingested real-time sensor metrics across the entire system:

* **`timestamp`**: Time of data capture.
* **`bearing_temp`**: Isolated component metric (scoped for Level 1).
* **`vibration` & `motor_rpm**`: System-level operational variables (scoped for Level 2).
* **`ambient_temp`**: External context (scoped for Level 3).

---

### 2. Level 1: `PartialDigitalTwin` (The Observer)

* **Scope:** Focuses strictly on a single isolated variable or subcomponent (`bearing_temp`).
* **Method — `ingest_bearing_data(temp)`:** Ingests the targeted metric and validates it against static safety thresholds (`temp_limit = 80.0°C`).
* **Output:** Basic diagnostic status (`NORMAL` vs. `OVERHEATING_WARNING`).

---

### 3. Level 2: `DigitalTwinClone` (The Mirror & Actuator)

* **Scope:** 1:1 reflection of the complete internal asset state (`bearing_temp`, `vibration`, `motor_rpm`).
* **Method — `sync_state(telemetry)`:** Synchronizes full system telemetry and performs **bi-directional closed-loop control**:
* If temperature exceeds **80.0°C**, it autonomously commands the actuator signal (`cooling_fan_active = True`).
* If temperature drops back below **75.0°C**, it turns the cooling fan off.


* **Output:** Synchronized telemetry snapshot and live control outputs.

---

### 4. Level 3: `AugmentedDigitalTwin` (The Optimizer)

* **Scope:** Entire system fused with external environmental variables and predictive algorithms.
* **Method — `evaluate_augmented_state(telemetry, grid_load_factor)`:**
1. **Environmental Context:** Combines internal heat with ambient conditions (`effective_thermal_stress = bearing_temp + 0.15 * ambient_temp`).
2. **Predictive Maintenance:** Calculates **Remaining Useful Life (RUL)** in hours, weighted by vibration and external grid stress.
3. **"What-If" Counterfactual Simulation:** Models the system response to an operational change (e.g., boosting motor speed by `+500 RPM` under current ambient heat).


* **Output:** Health risk index, estimated RUL hours, and hypothetical scenario forecasts.
