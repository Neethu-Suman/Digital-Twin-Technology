# MATLAB & Simulink Digital Twins

A complete framework for designing, deploying, and maintaining physics-based and data-driven Digital Twins using MATLAB®, Simulink®, and Simscape™.

## Overview

This repository provides design templates, model-order reduction (MOR) workflows, edge-to-cloud deployment scripts, and telemetry integration pipelines to construct synchronized virtual models of physical assets.

## Core Capabilities

* **Physics-Based Modeling:** Multi-domain physical modeling using Simscape (mechanical, electrical, thermal, fluid).
  
* **Model Order Reduction (MOR):** Linear and non-linear ROM generation via `Deep Learning Toolbox™` and `System Identification Toolbox™` for real-time edge execution.
  
* **State Estimation & Tracking:** Kalman Filters, unscented Kalman filters (UKF), and particle filters to continuously synchronize virtual state with noisy sensor streams.
  
* **Predictive Maintenance:** Remaining Useful Life (RUL) estimation and degradation modeling with `Predictive Maintenance Toolbox™`.
  
* **Deployment Flexibility:** Direct compilation to standalone C/C++ code (Simulink Coder™) or containerized microservices (MATLAB Production Server™).

## Prerequisites

* **MATLAB** (R2023b or later recommended)

* **Simulink**

* **Toolboxes:**

  * Simscape™

  * Predictive Maintenance Toolbox™

  * Control System Toolbox™

  * System Identification Toolbox™

  * MATLAB Coder™ / Simulink Coder™ (for edge export)

  * MATLAB Production Server™ (for cloud microservice deployment)

## Quick Start

### 1. Clone the Repository

```bash
git clone [https://github.com/your-org/matlab-digital-twin.git](https://github.com/your-org/matlab-digital-twin.git)
cd matlab-digital-twin

```

### 2. Initialize the MATLAB Environment

Launch MATLAB and run the startup script to set project paths and load workspace variables:

```matlab
>> run('setup_project.m')

```

### 3. Run the Digital Twin Mirror Demo

Execute a closed-loop twin simulation tracking live synthetic telemetry:

```matlab
% Load model and streaming test data
open_system('models/IndustrialPump_DigitalTwin.slx');

% Run synchronized simulation
simOut = sim('IndustrialPump_DigitalTwin.slx');

% Plot real vs. twin state response
plot_twin_comparison(simOut);

```

## Telemetry Ingestion Example (MQTT)

```matlab
% Subscribe to industrial IoT broker
brokerAddress = "tcp://iot-broker.internal:1883";
clientID = "MATLAB_DT_Client";
mqClient = mqttclient(brokerAddress, ClientID=clientID);

subscribe(mqClient, "assets/pump01/telemetry", Callback=@onTelemetryReceived);

function onTelemetryReceived(topic, data)
    payload = jsondecode(char(data));
    set_param('IndustrialPump_DigitalTwin/Measured_RPM', 'Value', num2str(payload.rpm));
end

```
